# Maktab-E-Khaleel

Installable (PWA) Maktab management app: students, fast attendance, fees, staff, reports, backup/restore.

- Works fully offline after the first load. Data is stored on the device.
- First launch: create the Owner account (username, password, recovery code). Keep the recovery code safe.
- Owner can add staff accounts; staff never see fees or salaries.
- Use **Settings → Backup** regularly. Clearing browser data erases records unless you have a backup.

Files: `index.html` (the app), `css/tailwind.css`, `sw.js`, `manifest.json`, `icons/`, `vercel.json`.
