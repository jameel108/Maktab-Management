# Deployment

1. Upload this whole folder to Vercel or Netlify (drag and drop). No build step, no keys needed.
2. Open the HTTPS link in Chrome on Android, tap ⋮, then **Install app**.
3. Optional APK: enter the HTTPS link at https://www.pwabuilder.com and download the Android package.

Notes: the app must be served over HTTPS (or localhost) for install and offline mode.
Data lives on each phone, so use one device per Maktab or back up and restore between devices.
Replace `icons/icon-192.png` and `icons/icon-512.png` with your own logo if you have one.
